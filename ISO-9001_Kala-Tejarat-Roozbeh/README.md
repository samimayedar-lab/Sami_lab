# مستندات ISO 9001:2015 – شرکت کالا تجارت روزبه

۱۹ فایل Word شامل نظامنامه، خط‌مشی و اهداف، ثبت ریسک، ۱۳ روش اجرایی، شرح وظایف و ۲۰ فرم.
فهرست کامل و مراحل اخذ گواهی در فایل `00_فهرست-اصلی-مدارک-و-راهنما.docx` آمده است.

- موارد داخل کروشه `[...]` را با اطلاعات واقعی شرکت تکمیل کنید.
- برای تغییر لوگو: فایل اصلی را با نام `logo.png` جایگزین کنید و در پوشه `build` دستور `node build.js` را اجرا کنید.
